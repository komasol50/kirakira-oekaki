# キラキラおえかき

幼児向けのAndroidおえかきアプリです。描いた線がきらきら光り、星やハートが舞います。
4〜5歳の子どもが説明なしで使えることと、親が安心して渡せることを目指して作りました。

## 主な機能

- **ブラシ4種**: きらきら・ほし・ハート・にじ（＋けしゴム）
- **18色のパレット**: 9色×2段。スクロールなしで全色を選べる
- **背景5種**: よぞら・はらっぱ・うみ・ほしぞら・にじ
- **スタンプ12種**: ユニコーン・ティアラ・おしろ・ねこ・ハート・リボン など
- **ほぞん**: 描いた絵を端末の写真アルバム（`Pictures/KirakiraOekaki`）とアプリ内ギャラリーに保存
- **もどる／すすむ**、ぜんぶけす（確認つき）
- **休憩タイマー**: 一定時間遊ぶと休憩画面になり、大人が足し算を解くまで解除できない。アプリを開き直してもリセットされない

## 設計方針

- UIの文字はひらがな・カタカナのみ。操作はアイコンと色で伝える
- 権限を一切要求しない（インターネット接続なし・広告なし・データ収集なし）
- 実在のキャラクターは使わない

## 技術構成

- Kotlin / Jetpack Compose
- minSdk 26（Android 8.0）/ targetSdk 35
- 外部ライブラリの追加なし

## ビルド方法

Android Studio で開いてそのまま実行するか、コマンドで:

```sh
./gradlew assembleDebug
```

## 制作について

[Claude Code](https://claude.com/claude-code) と対話しながら、使う子どもの反応を見て「要望を仕様にする → 実装 → 実機で確かめる」をくり返して作りました。
スタンプ・背景のイラストは画像生成AIで作成したものです。
